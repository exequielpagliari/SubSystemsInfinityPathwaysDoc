\doxysubsection{Detailed Description}
\doxylink{class_u_game_play_hub_subsystem}{UGame\+Play\+Hub\+Subsystem}

A game instance subsystem redesigned under an Event-\/\+Driven architecture. It manages and caches gameplay HUD metrics, streaks, timers, and cells data, providing direct getters and multicast delegates to instantly update UI elements and systems without per-\/frame interface overhead.
