SubSystemsInfinityPathways
SubSystemsInfinityPathways is an Unreal Engine module that provides reusable game-instance services for level management, gameplay progression, scoring, radio playback, and user settings. It exposes level data, gameplay metrics, and configuration through Unreal-reflected classes and Blueprint-accessible APIs, with support for Game Feature-based level assets.
