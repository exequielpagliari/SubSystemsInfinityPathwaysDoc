SubSystemsInfinityPathways
SubSystemsInfinityPathways is an Unreal Engine module that provides reusable game-instance services for level management, gameplay progression, scoring, radio playback, and user settings. It exposes level data, gameplay metrics, and configuration through Unreal-reflected classes and Blueprint-accessible APIs, with support for Game Feature-based level assets.

Detailed Description

GameMode falso solo para tests. Implementa las dos interfaces que consume UGamePlayHubSubsystem y devuelve valores fijos y modificables desde el test.

SUPUESTOS (si el compilador se queja en los override, revisar esto en las interfaces):

  • Todas las funciones son BlueprintNativeEvent (si alguna es BlueprintImplementableEvent no existe _Implementation y este mock tendria que ser un Blueprint).
  • Ninguna es const (si lo son, agregar const a los override).
  • Los tipos de retorno coinciden: float, int32, uint8, FText, UMaterialInterface*.
